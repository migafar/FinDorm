#  FinDorm
   ![FinDorm logo ](Images/Logo.jpg)
**Tələbələr üçün ağıllı ev/kirayə axtarış platforması.**

FinDorm tələbənin büdcəsinə uyğun və universitetinə ən yaxın evləri tapır, sıralayır və gündəlik yolun necə olacağını köçməzdən əvvəl göstərir.

## Problem

Tələbələr kirayə ev axtararkən çox vaxt itirir: elanlar müxtəlif yerlərdə dağınıqdır, büdcəyə uyğun variantı seçmək çətindir, evin universitetdən nə qədər uzaq olduğu isə yalnız köçəndən sonra bəlli olur.

## Həll

FinDorm bu addımları avtomatlaşdırır:

1. **Data toplama** – bazardakı ev elanlarını bir yerə yığır.
2. **Büdcənin hesablanması** – istifadəçinin gəlir mənbələrini (stipendiya + əlavə gəlir) nəzərə alır.
3. **Universitetə görə filtr** – tələbənin təhsil aldığı universitetə yaxınlığı müəyyən edir.
4. **Sıralama** – büdcəyə uyğun və ən yaxın evləri yuxarıda göstərir.
5. **Marşrut və vaxt** – hər ev üçün təxmini yolu və gediş vaxtını göstərir.


```
Gəlir məlumatı + Universitet
          
  Ev elanları (data)
          
  Büdcəyə görə filtr
          
  Yaxınlığa görə sıralama
          
  Marşrut + gediş vaxtı
```

## Əsas imkanlar

-  Gəlirə əsaslanan büdcə hesablaması
-  Universitetə yaxınlığa görə sıralama
-  Hər ev üçün təxmini marşrut
-  Gündəlik gediş vaxtı proqnozu
